# Промт для браузера: переиндексация в Google, Bing и остальных

Составлено 2026-09-18. Работает в паре с `docs/REINDEX_AFTER_V3.md`, где лежат
сами URL по приоритетам.

## Что уже делается скриптом, а что руками

**Скриптом — Bing, Yandex, Naver, Seznam.** Один раз после деплоя:

    npx tsx scripts/indexnow-ping.ts --dry-run
    npx tsx scripts/indexnow-ping.ts

Это IndexNow. Bing кормит Copilot, Yandex — русскую выдачу. Через него же
подхватывается Yahoo. Руками там делать нечего.

**Руками — только Google.** Google в IndexNow не участвует принципиально, и
единственный способ попросить переобход — Search Console. Квота «Request
indexing» примерно десяток URL в сутки, поэтому и нужен приоритетный список.

---

## Промт для агента в браузере

Вставить в Gemini in Chrome, Comet, Opera Neon или любой браузерный агент,
который умеет кликать. Перед запуском **войти в аккаунт** Search Console и
Bing Webmaster Tools — агент сам не залогинится.

```
Ты работаешь в моём браузере. Я уже залогинен. Задача — попросить поисковики
переобойти обновлённые страницы сайта easy-move-florida.com.

ВАЖНО: ничего не покупай, не меняй настройки сайта, не удаляй ресурсы и не
подтверждай ничего, что стоит денег. Только отправка на переобход.

ЧАСТЬ 1. Google Search Console

1. Открой https://search.google.com/search-console и выбери ресурс
   https://www.easy-move-florida.com/ (если там несколько — бери именно
   домен-ресурс, а не URL-префикс).

2. Слева открой «Файлы Sitemap» / "Sitemaps". В поле добавления введи
   sitemap.xml и нажми «Отправить». Если он уже есть в списке — всё равно
   отправь повторно: это сбрасывает дату последнего чтения.

3. Теперь по одному прогони URL ниже через «Проверка URL» / "URL Inspection" —
   это строка поиска вверху страницы. Для каждого:
   — вставь URL, дождись проверки,
   — нажми «Запросить индексирование» / "Request Indexing",
   — дождись подтверждения и переходи к следующему.

   Если Google скажет, что квота на сегодня исчерпана — остановись, запиши,
   на каком URL остановился, и скажи мне. Не пытайся обойти квоту.

   Список (по убыванию важности):
   https://www.easy-move-florida.com/reviews
   https://www.easy-move-florida.com/services
   https://www.easy-move-florida.com/moving-cost-miami
   https://www.easy-move-florida.com/moving-cost-hollywood
   https://www.easy-move-florida.com/moving-cost-aventura
   https://www.easy-move-florida.com/moving-cost-sunny-isles
   https://www.easy-move-florida.com/miami-movers
   https://www.easy-move-florida.com/ru/russkie-gruzchiki-miami
   https://www.easy-move-florida.com/ru/miami-movers
   https://www.easy-move-florida.com/services/storage-solutions

4. Слева открой «Страницы» / "Pages" → раздел с ошибками. Найди, есть ли
   ошибки про hreflang или «нет обратных тегов» / "no return tags". Сделай
   скриншот того, что увидишь, и покажи мне. Ничего не чини сам.

ЧАСТЬ 2. Bing Webmaster Tools

5. Открой https://www.bing.com/webmasters и выбери тот же сайт.

6. Раздел «Submit URLs» / «Отправить URL». Вставь весь список из шага 3 разом
   и отправь. У Bing квота щедрая, около 10 000 URL в день.

7. Раздел «Sitemaps» — переотправь sitemap.xml так же, как в Google.

ЧАСТЬ 3. Отчёт

8. Напиши мне коротко:
   — сколько URL приняла каждая система,
   — где упёрся в квоту, если упёрся,
   — что показала страница ошибок hreflang в Google,
   — любые предупреждения, которые выскочили.

Ничего не выдумывай: если какой-то шаг не получился, так и скажи.
```

## Чего этот промт НЕ делает, и почему

**Не трогает `/v2`, `/privacy` и `/terms`.** Первые два noindex. `/terms`
изменился по сути, но тоже noindex: его читают люди, а не поиск.

**Не просит переобход украинских страниц по одному.** Их 12, а квота Google —
десяток в сутки. Они уйдут вместе с sitemap; отдельная просьба на них потратит
квоту, которая нужнее cost-страницам.

**Не делает ничего с ИИ-ассистентами.** У ChatGPT, Claude и Perplexity нет
кнопки «переобойти». Они подтягивают свежую страницу либо через собственный
краулер, либо через Bing — то есть через шаг 6. Отдельного действия нет,
только ожидание.

## Что проверить через 2–3 недели

Повторить шесть живых выдач из `docs/ACTION-PLAN.md`. Отдельно спросить
ChatGPT и Perplexity «how much do movers cost in Miami» и «русские грузчики
Майами» — если оттуда всё ещё выпадает «from $1,500» или старый рейтинг, кэш
не обновился. Для первых недель это нормально.

В Search Console посмотреть, ушли ли ошибки hreflang по девяти русским
страницам и `/boca-raton-movers`. Это самый проверяемый результат всей работы:
либо они исчезли, либо нет.
