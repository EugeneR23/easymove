## Как подать запрос

### Вариант 1 — через GBP Support Form (рекомендую)

1. Зайди на https://support.google.com/business/contact/business_redressal_form
2. Выбери: "Edit business information" → "Business name"
3. Альтернативно: business.google.com → твой профиль → ⓘ Help (внизу слева) → "Need more help" → "Contact us"
4. Выбери канал контакта (email рекомендую — есть письменный след)

### Вариант 2 — Manage on Google Search

1. Зайди в Google Search в браузере где залогинен бизнес-аккаунт
2. Найди свой профиль ("EasyMove Elite Hollywood FL")
3. На карточке справа: "Edit profile" → "Business information" → "Name"
4. Введи новое название → Save
5. Если Google требует подтверждение — переходи к Варианту 1 с docs

## Если Google откажет

Самые частые причины отказа:
- **Думают что это другой бизнес.** Решение: предоставь LLC docs + сайт с тем же phone/address.
- **Думают что это keyword stuffing.** Решение: подчеркни что "EasyMove Elite" — точное юридическое название LLC, не маркетинговая фраза.
- **Заявление слишком общее.** Решение: повтори с большим количеством деталей и приложенных документов.

Если отказали — отвечай на тикет, не открывай новый. Цикл уточнений занимает 2-3 итерации обычно.
